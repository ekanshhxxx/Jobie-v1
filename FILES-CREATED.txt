================================================================================
                    HOW MESSAGES TRAVEL
================================================================================

Recruiter Sends:
  1. channel.sendMessage({ text: "..." })
  2. Stream Chat SDK queues message
  3. Sends via WebSocket to Stream servers
  4. Stream servers persist to database
  5. Stream broadcasts to channel members
  6. Candidate's WebSocket receives update
  7. SDK updates local channel state
  8. React component re-renders
  9. ✓ Candidate sees message in <100ms

NO POLLING. NO MANUAL SOCKETS. JUST STREAM CHAT!

================================================================================
                   COMMON ISSUES & FIXES
================================================================================

Issue: "Stream Chat is not configured"
Fix: Set STREAM_API_KEY and STREAM_API_SECRET in backend/.env
     Restart backend server

Issue: "Unauthorized" (401 error)
Fix: Token expired - login again and get new token
     Or verify JWT_SECRET matches

Issue: "jobiId is required"
Fix: This is a typo in validation (not your fault!)
     Always include jobId in POST /api/chat/stream/channel

Issue: "Cannot find module 'stream-chat'"
Fix: npm install stream-chat stream-chat-react
     In frontend directory

Issue: Messages don't appear
Fix: Check WebSocket connection in DevTools
     Verify both users are in same channel
     Check server logs for errors

                 ARCHITECTURE SUMMARY
================================================================================

Frontend (React + Next.js)
  ├─ app/recruiter/messages/page.tsx → Recruiter UI
  ├─ app/candidate/messages/page.tsx → Candidate UI
  └─ Uses: stream-chat-react components

Stream Chat SDK
  ├─ Handles: WebSocket, real-time sync, message persistence
  └─ Servers: stream-cdn.getstream.io (managed by Stream)

Backend (Node.js + Express)
  ├─ GET /api/chat/stream/auth → Returns Stream credentials
  ├─ GET /api/chat/stream/contacts → Returns contact list
  ├─ POST /api/chat/stream/channel → Creates/gets channel
  └─ Uses: streamService.ts for Stream integration

Database (Sequelize/SQL)
  ├─ Users, Jobs, Applications
  └─ Used to validate permissions and create contacts
